# AI Web Extractor and Summarizer

## Overview
This project is an AI-powered web content extractor and summarizer built using n8n, LangChain, and Groq.

## Workflow
- When Chat Message Received
- HTTP Request
- Code (JavaScript)
- Basic LLM Chain
- Groq Chat Model

## Features
- Fetch webpage content
- Clean HTML using JavaScript
- Generate AI summaries
- Interactive chat interface

## Technologies
- n8n
- Groq
- LangChain
- JavaScript

## How to Use
1. Import the workflow JSON into n8n.
2. Add your Groq API credentials.
3. Execute the workflow.
4. Send a webpage URL in the chat.
