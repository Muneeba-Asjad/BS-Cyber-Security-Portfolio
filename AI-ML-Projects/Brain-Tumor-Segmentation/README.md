# Brain Tumor Segmentation from MRI Scans
## Description
Brain Tumor Segmentation using Deep Learning (U-Net) for MRI images.

## Features
- MRI Image Upload
- Tumor Segmentation
- Dice Score
- IoU Score
- Accuracy
- Streamlit GUI

## Technologies
- Python
- PyTorch
- OpenCV
- Streamlit
- NumPy
- Scikit-Learn

## Model
U-Net
